# Shipping ID / Tracking Number Guide

## Overview
When updating an order status to "shipped" as an admin, you will be prompted to enter a tracking number. This tracking number is used to help customers track their shipments.

## Format Guidelines

The tracking number format depends on the shipping carrier you use. Here are common formats:

### Common Indian Shipping Carriers

**BlueDart**
- Format: Usually starts with letters followed by numbers
- Example: `B123456789` or `D123456789`
- Length: Typically 10-12 characters

**Delhivery**
- Format: Numeric or alphanumeric
- Example: `1234567890123` or `DLV1234567890`
- Length: Typically 12-14 characters

**FedEx**
- Format: 12-digit numeric
- Example: `123456789012`
- Length: Exactly 12 digits

**DTDC**
- Format: Numeric
- Example: `D12345678` or `12345678`
- Length: Typically 8-10 characters

**Ecom Express**
- Format: Numeric
- Example: `1234567890123`
- Length: Typically 12-14 digits

**Shiprocket / Other Aggregators**
- Format: Varies by carrier
- Example: Can include carrier prefix like `FED123456789` for FedEx via Shiprocket

## How to Enter

1. Navigate to Admin Dashboard → Orders
2. Click on an order to view details
3. Click the "Shipped" status button
4. Enter the tracking number when prompted
5. The tracking number will be saved and displayed to the customer

## Best Practices

- Always include the carrier name if possible (e.g., "FedEx: 123456789012")
- Double-check the tracking number before submitting
- Ensure the tracking number is valid and active
- Update the tracking number if it changes (contact support if needed)

## Customer View

Customers can see their tracking number on:
- Order details page
- Order status history
- Email notifications (if configured)

## Troubleshooting

**Tracking number not working?**
- Verify the number is correct
- Check if the carrier system is updated
- Contact the shipping carrier directly

**Need to update tracking number?**
- Currently, you may need to contact technical support to update an existing tracking number
- Future updates will allow direct editing of tracking numbers
